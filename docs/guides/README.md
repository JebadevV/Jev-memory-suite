# Guias

Propósito: índice dos guias de instalação, desenvolvimento, configuração, clientes, migração, atualização de upstream e solução de problemas. Público: usuários e contribuidores. Data: 2026-10-22.

| Guia | Quando usar |
|---|---|
| [Instalação](installation.md) | Primeira instalação, compilação dos motores e primeiro perfil |
| [Configuração](configuration.md) | Habilitar o Gateway, mudar portas e criar perfis |
| [Clientes](clients.md) | Registrar, verificar, lançar e validar Claude CLI, Codex CLI e Codex Desktop |
| [Projetos externos](external-projects.md) | Iniciar na pasta de qualquer projeto, com memória isolada e exemplos PowerShell |
| [Otimização de tokens](token-optimization.md) | Medir o uso do Jev, configurar o experimento com e sem roteamento e o protocolo de teste do Ponytail |
| [Migração do histórico](migration.md) | Trazer o histórico da instalação original do AI Memory, com backups, simulação, aplicação, relatório e rollback |
| [Desenvolvimento](development.md) | Build, lint, typecheck, testes e convenções do repositório |
| [Atualização de upstream](upstream-updates.md) | Trazer um novo commit de Jev Gateway ou AI Memory |
| [Solução de problemas](troubleshooting.md) | Portas, erros 401, `doctor`, marcador ausente, motores e hooks |

Operação diária e recuperação estão em [operação e recuperação](../runbooks/README.md).
